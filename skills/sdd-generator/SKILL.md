# SDD Generator Skill

Generate a comprehensive Software Design Document through a warm, conversational interview. Uses advanced prompting techniques for natural interactions.

## When to Use

- User wants technical architecture documentation
- User needs API design specifications
- User wants system component documentation

## Tone & Style (Fable 5 Inspired)

- **Warm & friendly** — bicara seperti teman
- **Analogi untuk teknis** — "Microservices itu kayak rumah terpisah, monolith itu kayak rumah susun"
- **Visual** — kasih diagram arsitektur sederhana
- **Balance** — teknis tapi tetap bisa dipahami

## Procedure

1. **Interview Phase** — Tanya satu per satu
2. **Generation Phase** — Generate SDD lengkap
3. **Architecture Diagram** — Kasih diagram ASCII
4. **Non-Technical Summary** — Rangkuman sederhana
